# VK TURN Proxy Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task by task. Track steps below.

**Goal:** Install and manage Moroka8 WRAP alongside WireGuard from Marketplace and export usable client settings.
**Architecture:** One service manager, existing WireGuard manager for backend and profiles, admin API and existing server page patterns.
**Tech Stack:** Python/FastAPI, Paramiko, Docker, Jinja/JavaScript.
**Spec:** docs/superpowers/specs/2026-11-10-vkturn-design.md

## Global Constraints
- Ordinary branch codex/vk-turn-proxy in the primary repository; no worktrees.
- Moroka8 v1.10.1, amd64/arm64 SHA-256 verification, WRAP always enabled, WireGuard backend only.
- No changes to existing WG profiles; no WRAP key in status, database, install logs or general config responses.
- User explicitly authorized implementation, push and panel VPS deployment; execute inline without additional process approvals.

## Review Focus
- Existing WireGuard must not be reinstalled or have keys/peers changed.
- Download, checksum, port and startup failures must be surfaced without replacing working services.
- VK exports must preserve profile secrets while leaving ordinary config and private TURN routes usable.
- Admin boundary and malformed input must prevent key disclosure and shell injection.
- Panel deployment must preserve encrypted SQLite state and support rollback.
